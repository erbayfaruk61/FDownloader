# Güvenlik Politikası (Security Policy)

FDownloader ekibi, kullanıcılarının ve projeyi kullanan sistemlerin güvenliğini en üst öncelik olarak kabul eder.

---

## 1. Desteklenen Sürümler

Aşağıdaki sürümler aktif olarak güvenlik güncellemeleri ve yamaları almaktadır:

| Sürüm | Destek Durumu |
|---|---|
| **1.5.x** | ✅ Aktif Destekleniyor |
| < 1.5.0 | ❌ Destek Sona Erdi (Lütfen güncel sürüme geçin) |

---

## 2. Güvenlik Açığı Bildirimi (Vulnerability Reporting)

FDownloader'da bir güvenlik açığı veya zafiyet tespit ettiyseniz, **lütfen bunu herkese açık GitHub Issue olarak bildirmeyin**.

Güvenlik açıklarını gizli tutarak sorumlu bildirim (Responsible Disclosure) ilkelerine uymanızı rica ederiz:

- **E-posta İletişimi:** `erbayfaruk61@gmail.com`
- **Konu Başlığı:** `[GÜVENLİK] Zafiyet Bildirimi - FDownloader`
- **İçerik:**
  - Güvenlik açığının özeti ve olası etki alanı
  - Adım adım yeniden üretme (PoC) adımları
  - Varsa çözüm veya yama önerisi

Bildiriminiz 48 saat içerisinde incelenecek ve düzeltme hazırlandığında GitHub Releases üzerinden güvenlik yaması olarak yayınlanacaktır.
